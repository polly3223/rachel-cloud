<objective>
Build the background health monitoring system that periodically checks all user containers and auto-restarts unhealthy ones with circuit breaker protection.

Purpose: Docker's built-in restart policy only handles container exits, not unhealthy containers. The health monitor fills this gap by polling container health status and restarting unhealthy containers before they affect users. The circuit breaker prevents infinite restart loops for containers with persistent issues.

    ```typescript
    interface CircuitState {
      restartCount: number;      // restarts in current window
      windowStart: number;       // timestamp of first restart in window
      isOpen: boolean;           // true = stop trying to restart
      lastRestartAt: number;     // for logging
    }
    ```

    Constants:
    - `SWEEP_INTERVAL_MS = 30_000` (30 seconds)
    - `MAX_RESTARTS_PER_HOUR = 3`
    - `CIRCUIT_WINDOW_MS = 3600_000` (1 hour)

    **Exports:**

    1. `HealthSweepResult` interface:
       ```typescript
       export interface HealthSweepResult {
         timestamp: number;
         containersChecked: number;
         healthy: number;
         unhealthy: number;
         restarted: string[];        // userIds that were restarted
         circuitOpen: string[];      // userIds where circuit breaker tripped
         errors: Array<{ userId: string; error: string }>;
       }
       ```

    2. `type HealthEventHandler = (result: HealthSweepResult) => void`

    3. `startHealthMonitor(onSweep: HealthEventHandler): void`
       - Starts the periodic health sweep interval
       - Calls `onSweep` after each sweep with results
       - Runs first sweep immediately

    4. `stopHealthMonitor(): void`
       - Clears the interval
       - Clean shutdown

    5. `runHealthSweep(): Promise<HealthSweepResult>`
       - Can be called manually (e.g., from HTTP API)
       - The core logic:

    **Health sweep algorithm:**

    ```
    1. List all containers (docker.listContainers(true))
    2. Filter to rachel-user-* containers
    3. For each container:
       a. Inspect to get health status
       b. If healthy or starting → count as healthy
       c. If unhealthy:
          - Check circuit breaker for this userId
          - If circuit is open → skip, report as circuit_open
          - If circuit is closed:
            - docker.restartContainer(name)
            - Increment circuit breaker counter
            - If counter >= MAX_RESTARTS_PER_HOUR → open circuit
            - Report as restarted
       d. If exited/dead:
          - Check if RestartPolicy should have restarted it
          - Try to start it (unless circuit is open)
    4. Return HealthSweepResult
    ```

    **Circuit breaker reset:**
    When checking circuit state, if `Date.now() - windowStart > CIRCUIT_WINDOW_MS`, reset the counter and close the circuit. This gives containers a fresh chance after the window expires.

    **Error handling:**
    - If inspecting a container fails, catch the error and add to `errors` array
    - Never let one container's error stop the sweep for other containers
    - Log errors but don't throw

    **Thread safety:**
    - Use a simple `sweeping` boolean to prevent concurrent sweeps
    - If a sweep is already running when the interval fires, skip it
