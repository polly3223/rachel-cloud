# Plan 14-01: New DB Schema — Users Table (telegram_id PK), Update Subscriptions FK

## Goal
Replace Better Auth's `user/session/account/verification` tables with a single `users` table keyed on Telegram user ID. Update subscriptions to reference `telegram_id`.

## Schema Changes

### New `users` Table
```typescript
export const users = sqliteTable('users', {
  telegramId: integer('telegram_id').primaryKey(),
  firstName: text('first_name'),
  lastName: text('last_name'),
  username: text('username'),        // @username on Telegram
  photoUrl: text('photo_url'),
  languageCode: text('language_code'),
  email: text('email'),              // Optional — from Polar if available
  createdAt: integer('created_at', { mode: 'timestamp' }).notNull().default(sql`(unixepoch())`),
  updatedAt: integer('updated_at', { mode: 'timestamp' }).notNull().default(sql`(unixepoch())`),
});
```

### Modified `subscriptions` Table
```typescript
export const subscriptions = sqliteTable('subscriptions', {
  id: text('id').primaryKey(),
  telegramId: integer('telegram_id').notNull().references(() => users.telegramId),
  // ... keep existing: polarCustomerId, polarSubscriptionId, status,
  //     currentPeriodEnd, gracePeriodEndsAt, vpsProvisioned,
  //     containerId, containerName, currentImage, targetImage, previousImage,
  //     provisioningStatus, provisionedAt, deprovisionedAt
  // Remove: userId (was Better Auth UUID)
});
```

### Tables to Remove
- `user` (Better Auth) — replaced by new `users`
- `session` (Better Auth) — replaced by lightweight signed cookies
- `account` (Better Auth) — Google OAuth accounts, no longer needed
- `verification` (Better Auth) — email verification, no longer needed
- `claudeTokens` — Claude OAuth tokens, no longer needed
- `healthChecks` — already removed in Phase 13

### Drizzle Relations Update
```typescript
export const usersRelations = relations(users, ({ one }) => ({
  subscription: one(subscriptions, {
    fields: [users.telegramId],
    references: [subscriptions.telegramId],
  }),
}));
```

## Migration Strategy
Since there are no production users yet:
1. Drop old Better Auth tables
2. Create new `users` table
3. Alter `subscriptions`: drop `userId`, add `telegramId`
4. Run via `bun drizzle-kit push`

## Files to Modify
- `src/lib/db/schema.ts` — complete rewrite of user-related tables
- Any file importing `users`, `sessions`, `accounts` from schema — update imports
- `src/lib/billing/subscription-manager.ts` — `userId` → `telegramId`
- `src/lib/admin/data.ts` — update user queries

## Order of Operations
1. Rewrite schema.ts (remove old tables, add new users table, update subscriptions)
2. Update all schema imports across codebase
3. Update subscription-manager to use telegramId
4. Run drizzle-kit push
5. Verify with drizzle-kit studio
