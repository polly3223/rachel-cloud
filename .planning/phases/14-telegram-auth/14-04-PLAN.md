# Plan 14-04: Polar Integration — Direct SDK Checkout + Webhooks with telegram_id

## Goal
Replace `@polar-sh/better-auth` plugin with direct Polar SDK calls. Pass `telegram_id` through checkout metadata so webhooks can identify the user.

## What @polar-sh/better-auth Did (to replicate)
1. **Checkout** — `polar.checkouts.create({ externalCustomerId, products, metadata, successUrl })`
2. **Portal** — `polar.customerSessions.create({ externalCustomerId })` → returns `customerPortalUrl`
3. **Webhooks** — `validateEvent(body, headers, secret)` from `@polar-sh/sdk/webhooks` → dispatch to handlers
4. **Customer sync** — auto-create Polar customer on user signup

## New Checkout Flow

### User clicks "Subscribe" on web dashboard
1. Frontend calls `POST /api/billing/checkout` with session cookie
2. Server creates checkout: `polar.checkouts.create({ ... })`
3. Returns Polar checkout URL → redirect user

```typescript
// POST /api/billing/checkout
const checkout = await polarClient.checkouts.create({
  products: [process.env.POLAR_PRODUCT_ID!],
  externalCustomerId: `tg_${session.telegramId}`,
  metadata: {
    telegram_id: String(session.telegramId),
  },
  customerMetadata: {
    telegram_id: String(session.telegramId),
  },
  successUrl: `${process.env.PUBLIC_BASE_URL}/dashboard?checkout=success`,
});
return json({ url: checkout.url });
```

## New Webhook Handler

### `src/routes/api/webhooks/polar/+server.ts`
Replace the Better Auth plugin webhook handler with direct SDK validation:

```typescript
import { validateEvent, WebhookVerificationError } from '@polar-sh/sdk/webhooks';

export async function POST({ request }) {
  const body = await request.text();
  const headers = {
    'webhook-id': request.headers.get('webhook-id') ?? '',
    'webhook-timestamp': request.headers.get('webhook-timestamp') ?? '',
    'webhook-signature': request.headers.get('webhook-signature') ?? '',
  };

  let event;
  try {
    event = validateEvent(body, headers, process.env.POLAR_WEBHOOK_SECRET!);
  } catch (err) {
    if (err instanceof WebhookVerificationError) {
      return json({ error: 'Invalid signature' }, { status: 400 });
    }
    return json({ error: 'Invalid payload' }, { status: 400 });
  }

  switch (event.type) {
    case 'subscription.active':
      await handleSubscriptionActive(event.data);
      break;
    case 'subscription.canceled':
      await handleSubscriptionCanceled(event.data);
      break;
    case 'subscription.revoked':
      await handleSubscriptionRevoked(event.data);
      break;
    case 'subscription.uncanceled':
      await handleSubscriptionUncanceled(event.data);
      break;
  }

  return json({ received: true });
}
```

### Webhook Handlers
Same logic as current auth/config.ts handlers, but find user by telegram_id:

```typescript
async function handleSubscriptionActive(data) {
  // Get telegram_id from subscription metadata or customer external ID
  const telegramId = data.metadata?.telegram_id
    || data.customer?.externalId?.replace('tg_', '');

  await updateSubscriptionStatus({
    telegramId: Number(telegramId),
    polarCustomerId: data.customerId,
    polarSubscriptionId: data.id,
    status: 'active',
    currentPeriodEnd: data.currentPeriodEnd ? new Date(data.currentPeriodEnd) : undefined,
    gracePeriodEndsAt: null,
  });
}
```
