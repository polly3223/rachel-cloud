# Plan 14-07: Update Landing Page, Onboarding Flow, and Admin Dashboard

## Goal
Update the public-facing pages to reflect the new Telegram-first model. Landing page gets new CTA, onboarding is simplified, admin uses Telegram auth.

## Landing Page Changes

### Hero Section
- **Old CTA**: "Sign Up" button → login/signup page
- **New CTA**: "Message @RachelAI on Telegram" button (links to https://t.me/RachelAIBot) + "Log in" link for existing users

### How It Works Section
- **Old**: 1) Sign up → 2) Connect Claude → 3) Create Telegram bot → 4) Deploy
- **New**: 1) Message Rachel on Telegram → 2) Subscribe ($20/mo) → 3) Start chatting

### Pricing Section
- Update to emphasize "all-inclusive" — no external subscription needed
- Remove any mention of "bring your own Claude subscription"

### Navigation
- Replace "Sign Up" / "Log In" buttons with "Message on Telegram" + "Dashboard" (if logged in)

## Onboarding Flow

### Old Flow
1. Sign up (email/Google)
2. Connect Claude account (OAuth)
3. Create Telegram bot (BotFather instructions)
4. Enter bot token
5. Subscribe (Polar checkout)
6. Deploy

### New Flow
1. Message @RachelAI on Telegram → /start → get link to web
2. Log in via Telegram Login Widget
3. Subscribe via Polar checkout
4. Container auto-provisioned → bot starts responding

### Onboarding Page Rewrite
- Remove Claude OAuth step entirely
- Remove BotFather instructions
- Keep Polar checkout integration
- Add "auto-deploy on payment" — webhook triggers container provisioning
- Show progress: Subscribing → Provisioning → Ready!

## Admin Dashboard

### Auth Change
- Login via Telegram Login Widget (same as user dashboard)
- Admin guard checks `session.telegramId === ADMIN_TELEGRAM_ID`

### Content Updates (minimal)
