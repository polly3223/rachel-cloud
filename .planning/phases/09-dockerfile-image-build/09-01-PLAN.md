<task type="auto">
  <name>Task 2: Create multi-stage Dockerfile</name>
  <files>/home/rachel/rachel8/Dockerfile</files>
  <action>
    Create `/home/rachel/rachel8/Dockerfile` with a two-stage build:

    **STAGE 1: Builder**
    - Base: `oven/bun:1.1.10-alpine AS builder`
    - WORKDIR: `/build`
    - Copy `package.json` and `bun.lock` first (layer caching -- deps only reinstall when lockfile changes)
    - Run `bun install --frozen-lockfile --production` (reproducible, no devDependencies)
    - Copy `src/`, `skills/`, `tsconfig.json` (application code)

    **STAGE 2: Runtime**
    - Base: `oven/bun:1.1.10-alpine AS runtime`
    - Install runtime system dependencies via apk (single RUN layer to minimize image layers):
      ```dockerfile
      RUN apk add --no-cache \
          git \
          ffmpeg \
          python3 \
          py3-pillow \
        && rm -rf /var/cache/apk/*
      ```
      - `git`: Required by Claude Agent SDK for tool execution
      - `ffmpeg`: Media processing (audio/video in skills)
      - `python3`: Required dependency for Pillow
      - `py3-pillow`: Image processing (pre-compiled Alpine package, NOT pip -- saves 180MB)

    - Create non-root user and data directory:
      ```dockerfile
      RUN addgroup -g 1000 rachel && \
          adduser -D -u 1000 -G rachel rachel && \
          mkdir -p /data && chown rachel:rachel /data
      ```

    - WORKDIR: `/app`

    - Copy from builder with correct ownership:
      ```dockerfile
      COPY --from=builder --chown=rachel:rachel /build/node_modules ./node_modules
      COPY --from=builder --chown=rachel:rachel /build/package.json .
      COPY --from=builder --chown=rachel:rachel /build/src ./src
      COPY --from=builder --chown=rachel:rachel /build/skills ./skills
      COPY --from=builder --chown=rachel:rachel /build/tsconfig.json .
      ```

    - **CRITICAL: Create a .env file stub.** Rachel8's `src/config/env.ts` calls `existsSync(".env")` and exits if the file is missing. In Docker, env vars are passed via `-e` flags, not `.env` files. Create an empty `.env` file so the existence check passes, and Bun.env will still pick up the runtime env vars:
      ```dockerfile
      RUN touch /app/.env && chown rachel:rachel /app/.env
      ```

    - Switch to non-root user: `USER rachel`

    - Declare volume: `VOLUME ["/data"]`

    - Set default environment variables:
      ```dockerfile
      ENV NODE_ENV=production \
          SHARED_FOLDER_PATH=/data \
          LOG_LEVEL=info
      ```

    - Add health check (process-level liveness probe):
      ```dockerfile
      HEALTHCHECK --interval=30s --timeout=10s --start-period=15s --retries=3 \
        CMD pgrep -f "bun.*index.ts" || exit 1
      ```
      Note: start-period is 15s (not 5s) because Rachel8 initializes memory system and Telegram connection at startup.

    - No EXPOSE directive (Rachel8 uses outbound Telegram polling, no inbound ports)

    - Entrypoint:
      ```dockerfile
      CMD ["bun", "run", "src/index.ts"]
      ```

    Add a header comment block at the top of the Dockerfile explaining what it builds, the expected image size (~280MB), and that secrets must be passed via runtime env vars.
  </action>

<task type="auto">
  <name>Task 3: Create build script</name>
  <files>/home/rachel/rachel8/scripts/build.sh</files>
  <action>
    Create `/home/rachel/rachel8/scripts/build.sh` as an executable build script that produces tagged Docker images.

    The script should:

    1. **Set strict mode:** `set -euo pipefail` (fail on errors, undefined vars, pipe failures)

    2. **Define variables:**
       - `IMAGE_NAME="rachel8"`
       - `SCRIPT_DIR`: resolve to the directory containing the script
       - `REPO_ROOT`: resolve to one directory above SCRIPT_DIR (the rachel8 repo root)
       - `GIT_SHORT_HASH`: capture via `git -C "$REPO_ROOT" rev-parse --short HEAD`
       - `GIT_TAG`: capture via `git -C "$REPO_ROOT" describe --tags --always 2>/dev/null || echo "$GIT_SHORT_HASH"`
       - `BUILD_DATE`: ISO 8601 format via `date -u +"%Y-%m-%dT%H:%M:%SZ"`

    3. **Print build info:**
       ```
       echo "Building Rachel8 Docker image..."
       echo "  Image:   ${IMAGE_NAME}"
       echo "  Version: ${GIT_TAG}"
       echo "  Commit:  ${GIT_SHORT_HASH}"
       echo "  Date:    ${BUILD_DATE}"
       echo ""
       ```

    4. **Run docker build** from the repo root:
       ```bash
       docker build \
         --tag "${IMAGE_NAME}:latest" \
         --tag "${IMAGE_NAME}:${GIT_SHORT_HASH}" \
         --label "org.opencontainers.image.created=${BUILD_DATE}" \
         --label "org.opencontainers.image.revision=${GIT_SHORT_HASH}" \
         --label "org.opencontainers.image.source=https://github.com/rachel/rachel8" \
         "$REPO_ROOT"
       ```

    5. **Print success summary:**
       ```bash
       echo ""
       echo "Build complete!"
       echo "  Tagged: ${IMAGE_NAME}:latest"
       echo "  Tagged: ${IMAGE_NAME}:${GIT_SHORT_HASH}"
       echo ""
       echo "Image size:"
       docker images "${IMAGE_NAME}:latest" --format "  {{.Size}}"
       ```

    Make the script executable: `chmod +x /home/rachel/rachel8/scripts/build.sh`

    Use `#!/usr/bin/env bash` as the shebang line for portability.
  </action>
